# User Guide

The User Guide ([USER_GUIDE.md](../USER_GUIDE.md)) maps out how to operate the AI Refinement Matrix Dashboard.

## Refinement Pipeline Steps
1. **Spec Excavation**: Separating functional/non-functional constraints, identifying gaps in raw notes.
2. **Story Slicing**: Slicing the excavated spec vertically via SPIDR framework.
3. **Adversary Stress Audit**: Adding edge case and security checks to Acceptance Criteria.
4. **Engineering Evaluation**: Auditing stories via Realist, generating checklists via Decomposer, adding test contracts via Guardian.
5. **Export**: Exporting refined stories to Markdown.
